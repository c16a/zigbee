# zigbee

A small Zig message broker.

## License

MIT. See [`LICENSE`](LICENSE.md).

## Requirements

- Zig 0.15.2

## Build

```sh
zig build
```

## Cross build

```sh
zig build cross
```

## Run

```sh
zig build run -- [port]
```

By default the server listens on `4222`.

## Test

```sh
zig build test
```
